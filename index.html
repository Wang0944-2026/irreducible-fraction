認識最簡分數

遊戲規則

📋 判斷題模式

判斷給定的分數是否已經是『最簡分數』。

✅ 什麼是最簡分數？

  • • 分子和分母的最大公因數是 1
  • • 無法再進一步約分
  • • 例如：3/4、5/7、2/9

❌ 不是最簡分數

  • • 分子和分母有公因數
  • • 可以繼續約分
  • • 例如：6/8 = 3/4、10/15 = 2/3

🎮 操作方式

滑鼠操作：

  • • 點擊「是」按鈕：認為是最簡分數
  • • 點擊「不是」按鈕：認為不是最簡分數

鍵盤快捷鍵：

  • • J 鍵或 ← 鍵：選擇「是」
  • • F 鍵或 → 鍵：選擇「不是」

✏️ 化簡題模式

將給定的分數化簡為『最簡分數』。

🔢 化簡步驟

  1. 找出分子和分母的最大公因數。
  2. 將分子和分母同時除以最大公因數。
  3. 得到最簡分數。

範例： 12/18 → GCD(12,18)=6 → 12÷6/18÷6 = 2/3。

🎮 操作方式

拖拉操作：

  • • 從下方數字區拖拉數字到答案框
  • • 上方框填入化簡後的分子
  • • 下方框填入化簡後的分母

修改答案：

  • • 點擊已填入的答案框可清除內容
  • • 重新拖拉正確的數字

跳過題目：

  • • 點擊「跳過此題」按鈕（扣3分）
  • • 或按 Enter 鍵快速跳過
  • • 兩個答案框都填入後會自動提交

⚡ 計分規則

  • • 答對一題：+1 分
  • • 連續答對 3 題以上：每題額外 +1 分
  • • 答錯：扣 1 分，連擊歸零並強制鎖定 2 秒
  • • 跳過題目：-3 分，連擊歸零
  • • 時間結束後顯示成績
  • • 記錄正確率和平均作答時間
  • • 追蹤最高連擊紀錄
